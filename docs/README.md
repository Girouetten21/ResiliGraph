## ⚡ Quick Links & Highlights

- **Interactive Canvas Engine:** 60 FPS HTML5 Canvas with sub-pixel Bézier curve routing and concentric rounded halos.
- **Realistic Telemetry:** Real-time calculation of Ingress Throughput, p50/p95/p99 Latency percentiles, and Infrastructure Availability.
- **Chaos Engineering Drills:** Automated Chaos Monkey, 10x traffic surges, synthetic HTTP 500 error injections, and network latency jitter.
- **Automated SRE Scorecard:** One-click reliability benchmark that audits Single Points of Failure (SPOF) and generates resilience grades (A+ to F).
- **Infrastructure as Code (IaC):** One-click generation of production-ready `docker-compose.yml`, AWS Terraform (`main.tf`), and Markdown Living Specs.
- **Custom Topologies:** Unlimited persistent topology creation, renaming, and snapshot management with confirmation safety.
